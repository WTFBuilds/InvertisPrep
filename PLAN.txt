PROJECT OVERVIEW
================================================================================
InvertisPrep is a Previous Year Question (PYQ) paper management system for 
Invertis University. Students can browse and download PYQ papers filtered by 
department, branch, semester, session, and exam type. Admins can upload papers 
through a secure admin panel.

CORE CONCEPT: FLAT STORAGE + METADATA FILTERING
================================================================================
Instead of maintaining complex nested folder structures in Cloudinary, we use:

✅ FLAT CLOUDINARY STORAGE: All PDFs stored in single folder → invertis/pyq/
✅ RICH MONGODB METADATA: Complete filtering data stored in database
✅ SMART QUERYING: Filter papers by querying MongoDB, not folder structure
✅ DIRECT DOWNLOADS: Cloudinary URLs stored in each document for instant access

WHY THIS APPROACH?
- Simple to maintain (no nested folders to manage)
- Flexible querying (any combination of filters)
- Fast performance (MongoDB indexes)
- Scalable (easy to add new metadata fields)

UPLOAD WORKFLOW (ADMIN)
================================================================================

1. ADMIN FILLS UPLOAD FORM
---------------------------
Fields:
- Department (dropdown)
- Branch (dropdown, filtered by department)
- Session (dropdown)
- Semester (dropdown, 1-8 based on branch)
- Subject Name (text input, e.g., "Data Structures")
- Subject Code (text input, e.g., "CSE301")
- Exam Type (dropdown: Mid-Term, End-Term, Sessional)
- Year (number input, e.g., 2024)
- PDF File (file upload)

2. BACKEND PROCESSING
---------------------
a) Receive multipart/form-data with PDF file
b) Validate all required fields
c) Upload PDF to Cloudinary (invertis/pyq/ folder)
   - Get back: secure_url, public_id, bytes
d) Create PYQPaper document in MongoDB with:
   - All form metadata
   - cloudinaryUrl: secure_url
   - cloudinaryPublicId: public_id
   - fileName: original filename
   - fileSize: bytes
   - uploadedBy: admin's userId
   - verified: false (needs approval)
e) Return success response with paper details

3. CLOUDINARY SERVICE CODE
---------------------------
async function uploadPDF(file, metadata) {
  const result = await cloudinary.uploader.upload(file.path, {
    folder: 'invertis/pyq',
    resource_type: 'raw',
    format: 'pdf',
    public_id: `${metadata.subjectCode}_${metadata.examType}_${Date.now()}`,
    tags: [metadata.subjectCode, metadata.examType],
  });

  return {
    cloudinaryUrl: result.secure_url,
    cloudinaryPublicId: result.public_id,
    fileSize: result.bytes,
  };
}

Controller:
async function getPapers(req, res) {
  const { departmentId, branchId, sessionId, semester, examType } = req.query;
  
  // Build dynamic filter
  const filter = { verified: true, isActive: true };
  if (departmentId) filter.departmentId = departmentId;
  if (branchId) filter.branchId = branchId;
  if (sessionId) filter.sessionId = sessionId;
  if (semester) filter.semester = parseInt(semester);
  if (examType) filter.examType = examType;
  
  // Query MongoDB with filters and populate references
  const papers = await PYQPaper.find(filter)
    .populate('departmentId', 'name displayName')
    .populate('branchId', 'name')
    .populate('sessionId', 'name')
    .sort({ year: -1, downloads: -1 })
    .limit(100);
  
  res.json({ success: true, count: papers.length, papers });
}
